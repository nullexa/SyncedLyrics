# SyncedLyrics
A firefox extention to extract Word-by-word synced lyrics from Youtube Music using Better Lyrics (https://better-lyrics.boidu.dev/) extention

> [!IMPORTANT]
> To this extension to successfully extract the lyrics, you have to wait until the 'Better Lyrics' extension fully sync up. If not, it will extract with inaccurate timestamps

### Permissions
- activeTab
- and host permissions to " https://music.youtube.com/* "
